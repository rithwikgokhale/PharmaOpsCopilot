# CDF artefacts (skeleton, not a project)

This folder is **not** a Cognite Toolkit project. There is no `cdf.toml`, no project id, and nothing here can `cdf deploy` on its own. The files are a field-engineering sketch of what would sit *beside* a Toolkit project that already deployed the [ISA-88/95 manufacturing data model pack](https://docs.cognite.com/cdf/deploy/cdf_toolkit/references/packages/isa_data_model).

| Path | What it is |
|---|---|
| [`modules/pharmaops_deviation/`](./modules/pharmaops_deviation/) | Toolkit module: `PharmaDeviation` view, `BatchEvent` Records container, `BasicArchive` stream, plus the generated Atlas agent/skill. Drop this into a Toolkit project after the ISA pack. |
| [`agents/pharmaops-triage/`](./agents/pharmaops-triage/) | Cognite CLI agent + eval suite. Regenerated by `npm run export:atlas`. Do not hand-edit. |

The React app and the local MCP server read synthetic JSON, not CDF. `CdfDataProvider` is a stub. See [COGNITE_MAPPING.md](../COGNITE_MAPPING.md).
