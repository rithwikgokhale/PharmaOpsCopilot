# `pharmaops_deviation` Toolkit module

Small extension meant to sit **beside** `isa_manufacturing_extension` (`dp:models:isa_manufacturing_extension`, enterprise space `dm_dom_isa_manufacturing`). It does **not** copy the 26 ISA views.

| Resource | Path | Notes |
|---|---|---|
| Spaces | `data_modeling/*.space.yaml` | `sp_pharmaops_model`, `sp_pharmaops_records` |
| `PharmaDeviation` container + view | `data_modeling/PharmaDeviation.*` | Quality record on an ISA-88 Batch. Implements `CogniteDescribable` + `CogniteSourceable` from `cdf_cdm` / `v1`. Does **not** implement `CogniteActivity`. |
| `PharmaOps` data model | `data_modeling/PharmaOps.datamodel.yaml` | Contains only the deviation view. |
| `BatchEvent` Records container | `data_modeling/BatchEvent.container.yaml` | `usedFor: record`. High-volume events/alarms/operator actions. See [Records and streams](https://docs.cognite.com/cdf/dm/records/concepts/records_and_streams). |
| Stream | `streams/batch_events.Streams.yaml` | Template `BasicArchive` — immutable once written. Filename suffix `Streams.yaml` is required by Toolkit ≥ 0.8.0. |
| Agent / skill | `agents/` | Generated by `npm run export:atlas`. Do not hand-edit. |

Direct relations on `PharmaDeviation.batch` / `.equipment` do not pin `source` to ISA views, so this skeleton does not invent a pack version. Descriptions name the intended targets (`isa_manufacturing:Batch`, `isa_manufacturing:Equipment`).

This module cannot deploy from this repository. A real project still needs `cdf.toml`, the ISA pack, extractors / RAW / transformations (the local stand-in is `scripts/contextualize.py`), and a CDF tenant.
